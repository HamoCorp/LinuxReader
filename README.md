# LinuxReader
Dyslexia friendly Linux read high lighted texts to tts

# install

set a speach dispatcher use espeak, piper or any other learn about that here [wiki.archlinux_speech_dispatcher](https://wiki.archlinux.org/title/Speech_dispatcher)

test it works with:

```spd-say "test"```

install wl-clipboard to capture clipboard on wayland

```sudo pacman -S wl-clipboard```

Download the file from this githup store on your pc then set the python to executable

```chmod +x TextReader.py```

then add this to shortcuts in your desktop environment settings
