# LinuxReader
Dyslexia friendly Linux read highlighted texts with tts with a hotkey. similar to browser extentions like speakit but works across the whole Linux pc even read from the terminal 

# install

if not already installed, set a speach dispatcher use espeak, piper or any other learn about that here [wiki.archlinux_speech_dispatcher](https://wiki.archlinux.org/title/Speech_dispatcher)

test speak dispatcher is installed and works with:

```spd-say "test"```

install wl-clipboard to capture highlighted text on wayland

```sudo pacman -S wl-clipboard```

Download the LinuxReader to your pc then set the python to executable

```chmod +x LinuxReader.py```

then add this to shortcuts in your desktop environment settings
